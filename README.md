# Homebrew Tap

This repository contains Homebrew formulae maintained by their respective project release workflows.

## Add This Tap

```bash
brew tap lucaschlomski/tap
```

## Available Formulae

| Formula | Description |
| --- | --- |
| `capture-sync` | Controlled rsync transfers over SSH with optional snapshots. |

Formulae are added and maintained automatically by the release workflows of projects published through this tap.
